# Polychain Capital Project Summary

Polychain Capital is a full-stack cryptocurrency investment-platform application with a polished dark-and-gold web interface.

Users can register and verify their email, manage a crypto wallet, submit deposits and withdrawals, invest in fixed-return plans, track accrued profits, earn referral commissions, complete KYC, and contact support through tickets. It also includes a public marketing site with plan comparisons, a return calculator, testimonials, FAQ, newsletter, and contact form.

Administrators have a separate console to manage users, manually review deposits and withdrawals, configure investment plans and site settings, handle support tickets, view reports, and review audit logs.

Technically, it uses a Next.js/React frontend, an Express REST API, PostgreSQL with Prisma, and JWT/cookie-based authentication. Deposits and withdrawals are workflow records handled through configured wallet addresses and admin review—not direct automated blockchain integrations.
